# Aldi cart (v7.2) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Send to Aldi cart: an Aldi list's checked products go into the user's own aldi.us cart through a pasted session cookie.

**Architecture:** `aldi.py` gains `account(sid)` and `fill_cart(sid, wanted)` on a per-call httpx client carrying the cookie. Storage keeps the cookie in `aldi_session.json`. `push` dispatches Aldi lists to `fill_cart`; the page adds a connect dialog and the send button.

**Tech Stack:** httpx with `MockTransport`, FastAPI, vanilla JS.

Design: `docs/plans/2026-11-06-aldi-cart-design.md`.
